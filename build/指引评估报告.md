# 《成人健康体检项目推荐指引（2025年版）》科学性与完整性评估
## —— 兼论对老年人群的覆盖充分性

> 评估对象：工作区内 5 份文件（附件1–5）
> 文件身份：国家卫生健康委办公厅 **国卫办医政函〔2025〕412号**（2025-10-28）
> 评估目的：为开发面向普通人与老年人的**非营利体检项目决策工具**提供依据

---

## 一、结论摘要

| 维度 | 评价 | 要点 |
|---|---|---|
| **权威性** | ★★★★★ | 国家卫健委正式印发，行业"新国标"，可作为工具的唯一推荐依据 |
| **理念科学性** | ★★★★☆ | "1+X"风险分层替代固定套餐，方向完全正确 |
| **部分核心项目** | ★★★★☆ | 肺癌用 LDCT、结直肠癌用结肠镜、心血管用 China-PAR，与国际一致 |
| **内部逻辑完整性** | ★★☆☆☆ | 附件1 与附件5 不闭环；附件3 与附件5 存在映射缺口 |
| **可执行性** | ★★☆☆☆ | 无筛查频次、无证据分级、无年龄上限 |
| **老年人覆盖** | ★☆☆☆☆ | **完全缺失老年医学维度，无法覆盖老年潜在疾病排查** |

**一句话**：作为"体检机构设项的参考框架"是合格且权威的；但作为"给普通人和老人直接使用的工具"，它**留了约七成的工作量需要我们自己补**——尤其是老年人群。

## 二、指引的基本结构与定位

- **适用范围**：18 岁及以上成年人群健康体检。
- **明确排除**：职业健康检查、从业人员体检、入学/入伍/结婚登记等专项体检、**基本公共卫生服务项目提供的健康体检**、孕前优生健康检查、专项疾病筛查普查。
- **推荐逻辑**（附件4 流程图实测）：
  ```
  健康体检自测问卷 → 初步评估健康状况 → 慢性病风险评估
        ├── 无慢性病风险 ──→ 基本体检项目
        └── 有风险/已诊断 ─→ 基本体检项目 + 慢性病风险筛查项目
  ```
- **三级体系**："健康体检自测问卷 + 基本体检项目 + 慢性病风险筛查"。

> ⚠️ **重要边界**：指引**明确把"基本公共卫生服务项目提供的健康体检"排除在外**——而 65 岁以上老年人每年一次的免费体检正属于该类。也就是说，**国家这份体检指引在设计上就没有把老年人当作目标人群**，老年人另有《国家基本公共卫生服务规范》管理。这对我们做"面向老人"的工具是关键前提。

## 三、科学性：哪些是可靠的

1. **肺癌**：高风险人群用**胸部低剂量 CT**（优先推荐）——与美国 USPSTF 的 LDCT 筛查思路一致。
2. **结直肠癌**：优先推荐**结肠镜**；风险评分表（年龄/性别/吸烟/BMI/家族史，≥4 分）为量化模型，优于主观判断。
3. **心血管**：采用 **ASCVD 10 年风险 + 余生风险** 分层，且与 China-PAR 模型衔接（可对接国家心血管病中心的官方计算器）。
4. **糖尿病 / COPD**：内置**中国糖尿病风险评分表**与 **COPD 筛查问卷（≥16 分）**，是经过验证的量表，可直接计算。
5. **筛查方法选择总体克制**：胃癌用胃镜、食管癌用内镜、肝癌用 AFP+超声、乳腺癌用 X 线、前列腺癌用 PSA——均为国内外公认手段。
6. **基础项目覆盖合理**：血尿便常规、肝肾功能、血脂血糖、心电图、腹部超声、40 岁以上加肺功能与骨密度，构成合理"底盘"。

## 四、完整性缺陷（已程序化验证）

### 4.1 附件1 问卷与附件5 判定标准**不闭环**（最严重）

附件5 的 13 类高风险人群判定，共需约 **75 项输入**；逐一比对附件1 实际采集字段后，**约 70% 的输入附件1 根本没有采集**：

| 风险人群 | 判定所需但附件1 未采集的关键字段 |
|---|---|
| 心血管病 | LDL-C/总胆固醇（需检验后才有）、慢性肾脏病**分期** |
| 糖尿病 | **身高体重(BMI)、腰围、收缩压**、糖尿病家族史、妊娠糖尿病/巨大儿史、多囊卵巢、黑棘皮病、胰腺炎史、类固醇用药、抗精神病/抑郁药、脂肪肝、糖尿病前期史 |
| COPD | **BMI、慢性咳嗽、气促、生物燃料、呼吸系统疾病家族史** |
| 肺癌 | **职业暴露史（石棉/氡/铍/铬/镉/镍/硅/煤烟）**、一级亲属肺癌史 |
| 结直肠癌 | **BMI**、林奇综合征/FAP |
| 胃癌 | **胃癌高发地区居住、一级亲属胃癌史、幽门螺杆菌检测、癌前疾病** |
| 肝癌 | **乙肝/丙肝感染、脂肪肝、黄曲霉毒素暴露、肝硬化、肝癌家族史** |
| 乳腺癌 | **月经初潮/绝经年龄、哺乳史、活产史、流产次数、乳腺活检史、激素替代治疗、BRCA1/2、二级亲属史** |
| 前列腺癌 | 前列腺癌家族史、BRCA2 |
| 卵巢癌 | 家族史、BRCA1/2、林奇综合征 |
| 食管癌 | **高发地区居住、一级亲属食管癌史、热烫/腌制饮食、癌前疾病** |
| 甲状腺癌 | **童年头颈部放射史、全身放疗史、家族史** |
| 认知功能障碍 | 痴呆危险因素、认知障碍家族史、主观认知下降 |

**后果**：若直接照搬附件1，工具将**无法触发附件5 中绝大多数风险判定**，"1+X"体系会退化成"人人一套基础套餐"。**这是我们做工具时必须自行扩展问卷的地方。**

### 4.2 附件3 与附件5 存在映射缺口

附件3 列出 **19 个**疾病方向的筛查项目，附件5 只定义了 **13 类**高风险人群。以下 4 个方向**有筛查项目却没有任何风险人群定义**，因而无法由风险评估触发：

- ✗ **胰腺癌**（附件3 却列为"优先推荐 CA19-9 + 胰腺增强CT"）
- ✗ **骨质疏松**（附件3 优先推荐双能 X 线骨密度、定量CT）
- ✗ **慢性肾病**（附件3 优先推荐尿微量白蛋白/肌酐比值、胱抑素C）
- ✗ **肥胖**（附件3 优先推荐餐后2h血糖+胰岛素）

反向地，附件5 定义"心血管病风险人群"过于笼统，未细分**高血压 / 冠心病 / 脑卒中**，而附件3 是分三条列项目的——**判出"心血管高风险"后该选哪一条，指引没有规则**。

### 4.3 无筛查频次、无证据分级、无年龄上限（全文扫描结果）

对全部 5 份文件全文（7,687 字）做正则扫描：

| 检索项 | 命中次数 | 含义 |
|---|---|---|
| 频次 / 间隔 / 每年 / 复查周期 | **0** | 不规定"多久查一次" |
| 证据等级 / 推荐强度 / GRADE | **0** | 不标注证据质量，"优先推荐/可选"无强度定义 |
| 预期寿命 / 年龄上限 / 停止筛查 | **0** | 不设筛查终止条件 |
| 老年人 / 老年人群 / 65岁 / 75岁 | **0** | **无老年人专章、无 65 岁以上任何规定** |
| 隐私 / 知情同意 | **0** | 无个人信息处理条款 |

### 4.4 其他逻辑问题

- **心理量表数据成为"孤儿"**：附件1 采集 GAD-7、PHQ-9，但附件5 无对应风险判定，附件3 也无心理健康筛查项目——**采了不用**。
- **鸡生蛋问题**：附件5 心血管判定依赖血脂值，但问卷在检验前填写，风险分层**无法在检前完成**。
- **宫颈癌路径不一致**：HPV + 宫颈细胞学被放进附件2"基本项目"（人人默认），却未在附件5 定义风险人群，也无年龄/性生活史限定。
- **"可选项目"清单过长且无护栏**：附件3 共 19 条"可选项目"行，在缺乏证据分级的情况下，**极易成为体检机构推销加项的清单**。

## 五、老年人覆盖评估（核心问题）

### 5.1 全文扫描：老年医学维度几乎全部缺失

| 肌少症（握力、步速、肌肉量） | ✗ 完全未提及 |
| 衰弱 frailty（FRAIL、Fried） | ✗ 完全未提及 |

### 5.2 判断

**结论：这份指引不能完整覆盖老年人的潜在疾病排查。** 三条硬理由：

1. **目标人群就排除了老年人**——指引明确不涵盖"基本公共卫生服务项目提供的健康体检"，而 65 岁以上老年人免费年度体检正属该类。
2. **缺的是老年医学的核心**——老年人健康风险主要来自**功能衰退与老年综合征**（失能、跌倒、肌少症、衰弱、营养不良、多重用药、失禁、认知与情绪），而指引是**按"病"组织**的（心血管/肿瘤/糖尿病/COPD），几乎没有"按功能"组织的内容。**按病筛查查不出"正在失能"的老人。**
3. **没有做"减法"的机制**——老年人最大的筛查风险是**过度诊断与过度检查**。指引无频次、无年龄上限、无预期寿命/衰弱调整规则，直接套用于 80 岁老人会导致：结肠镜、胃镜、LDCT 等侵袭性检查被不加区分地推荐。

> 换言之，老年人使用该指引时，**"漏查"（功能与老年综合征）与"过查"（侵袭性肿瘤筛查）风险同时存在**。

### 5.3 可直接复用的老年相关部分

- 40 岁以上加**肺功能、骨密度**（附件2）——对老年人是有效的
- **认知功能障碍**筛查路径（≥50 岁推荐脑认知健康筛查，附件3 + 附件5）——可直接用
- **跌倒/骨折**的间接入口：骨密度 + 定量CT（附件3 骨质疏松）
- 慢病风险评分表（糖尿病/COPD/结直肠癌）——可直接计算

### 5.4 老年医学界的权威依据（协和老年医学科观点）

北京协和医院老年医学科「和年苑」在《查出来，然后呢？——健康老人的疾病筛查与干预》中系统论述了老年人过度筛查问题，与上述判断一致：

- **年龄越大，筛查的边际获益越小，假阳性与过度治疗风险越大**；**75 岁是关键分界点**，多数筛查和一级预防的证据在该年龄段严重不足。
- **惯性"多查"的代价被忽视**：即便面对 80 岁晚期肺癌患者，仍有 **25%** 的医生会建议结直肠癌筛查。
- **乳腺钼靶**：近 9 万人、25 年加拿大随访显示，筛查组与未筛查组乳腺癌累计死亡率**几乎相同**；50–69 岁每两年一次较合理，但**大量 75 岁以上女性仍在常规筛查**。
- **PSA**：每 1000 名受检男性仅 **1 人**可能获益，却有多达 **43 人**受到严重伤害；80 岁男性约 70% 存在前列腺癌，仅 3% 因此死亡。
- **结肠镜**：80 岁后应先评估**预期寿命和操作风险**，获益未必大于代价。
- **过度降压**在 80 岁以上人群与更高死亡率相关；重度使用降压药者**严重跌倒风险增加 40%**。
- **被严重低估的领域**：听力损失影响**超 50% 的 70 岁以上老人**，与抑郁、社交孤立和痴呆相关，但仅 15% 需要助听器的人真正使用；约 70% 老年人有牙周疾病，专业口腔护理可使养老机构**致死性肺炎降低达 40%**；疫苗接种是少数"明确有益"的预防（高剂量流感疫苗使 65 岁以上住院后 30 天死亡风险降低 36%，带状疱疹疫苗有效率 91%–97%）。

> **对我们的意义**：听力、口腔、疫苗、跌倒、多重用药这些**被指引完全忽略**的领域，恰恰是老年人获益最大的地方。工具若只做"按病筛查"，会把老人导向收益最小、伤害最大的部分。

### 5.5 与《老年人健康管理服务规范（2026年）》的对照（关键）

国家对老年人**另有一套体系**，与本次评估的体检指引互不覆盖：

| 内容 | 老年人健康管理服务规范（2026年） | 成人健康体检项目推荐指引（2025年版） |
|---|---|---|
| 对象 | 辖区内 **65 岁及以上**常住居民 | 18 岁以上成人（**排除**基本公卫体检） |
| 频次 | **每年 1 次**（明确） | **无任何频次规定** |
| 生活自理能力评估 | ✓ 有（问诊评估） | ✗ 无 |
| 口腔 / 视力 / 听力 / **运动功能**粗测 | ✓ 有 | △ 口腔、视力、听力有；**运动功能无** |
| 肿瘤筛查 | ✗ **完全没有**（仅腹部B超） | ✓ 有（10 余种癌） |
| 认知筛查量表（MMSE/MoCA） | ✗ 无（仅"认知和情感"健康指导） | ✓ 有 |
| 骨密度 | ✗ **无** | ✓ 40 岁以上有 |
| 肺功能 | ✗ 无 | ✓ 40 岁以上有 |
| 疫苗接种 / 防跌倒 / 意外伤害 / 自救指导 | ✓ **有**（健康指导项） | ✗ 无 |
| 辅助检查 | 血尿常规、肝肾功能、空腹血糖、血脂、心电图、腹部B超 | 更全面（加甲功、同型半胱氨酸、HbA1c、胸片、人体成分等） |

**核心结论**：
- **老年人规范**管的是"功能与慢病基础"，**完全不查肿瘤**；
- **2025 体检指引**管的是"按病筛查"，**完全不管功能与老年综合征**；
- **两者都不覆盖"老年人潜在疾病排查"的完整需求**，且指引在设计上已把老年人排除。

> 对我们的工具而言，这意味着不能只做"指引的电子化"，而应**合并两套体系并补齐缺口**：以指引的疾病筛查为骨架，叠加老年人规范的功能评估项，再补上二者都缺的**衰弱、肌少症、跌倒、营养、多重用药、失禁、腹主动脉瘤、听力标准化筛查**，并加入**频次与筛查停止条件**。

## 六、对工具开发的直接含义

1. **不能照搬附件1**：必须新建一份**扩展问卷**，补齐第四节列出的约 70% 缺失字段（尤其是 BMI、腰围、血压、月经生育史、肝炎史、职业暴露、高发地区、家族史细化到具体癌种）。
2. **需要自建"风险人群 → 筛查项目"的映射表**：补齐附件5 缺失的 4 个风险人群定义（胰腺癌、骨质疏松、慢性肾病、肥胖），并把心血管拆分为高血压/冠心病/脑卒中三条。
3. **必须增加老年人模块**：按 WHO ICOPE 的"内在能力"或 CGA 维度，补充**功能（ADL/IADL）、跌倒、肌少症、衰弱、营养、多重用药、失禁、听力、情绪、社会支持**的筛查工具。
4. **必须增加"减法"规则**：按年龄/衰弱/预期寿命设定筛查**停止条件**，并标注每项的**筛查间隔**。
5. **必须增加证据分级**：对附件3 的 19 条"可选项目"逐项标注证据强度，把证据薄弱的项目降级或剔除，避免工具沦为推销清单。
6. **隐私最小化**：附件1 采集姓名、证件号码、电话、家庭住址——**工具一律不要采集**，只保留计算风险所必需的字段。
7. **面向老人的可用性**：附件1 的"饮酒单位换算""GAD-7/PHQ-9 自评"对低教育程度老人门槛过高，需要大幅简化 + 语音/家属代填支持。

## 七、证据强度核查（第三方循证核查结论）

对附件 3 的"优先推荐/可选项目"逐项核查后，发现 **3 项应删除、5 项须降级或加护栏**。**注意：这是我方补充核查的结果，指引本身完全未做证据分级**（全文 GRADE/证据等级 0 命中）。

### 7.1 建议删除（无筛查证据，且与卫健委自身 2024 年方案冲突）

| 项目 | 在指引中的位置 | 核查结论 |
|---|---|---|
| **异常糖链糖蛋白（TAP）** | 肺癌/肝癌/乳腺癌"可选" | 无筛查 RCT、无死亡率终点、无指南推荐；国家卫健委《肺癌筛查与早诊早治方案(2024版)》**明确不推荐生物标志物检测用于肺癌筛查** |
| **乳腺热层析成像** | 乳腺癌"可选" | FDA(2023)：**无任何科学证据支持**其作为独立乳腺癌筛查手段，仅批准为辅助工具 |
| **肺癌血清标志物组合**（ProGRP/NSE/CYFRA21-1/SCC/自身抗体） | 肺癌"可选" | 同上，2024 版方案明确不推荐 |

### 7.2 须重大降级或加护栏

| 项目 | 指引定位 | 问题 | 建议 |
|---|---|---|---|
| **甲状腺及颈部淋巴结超声** | 甲状腺癌"**优先推荐**" | USPSTF **D 级**（反对无症状成人筛查）；中华医学会 2023《甲状腺结节和分化型甲状腺癌诊治指南(第二版)》**不推荐普通人群筛查**；韩国经验（NEJM 2014）发病率升约 15 倍而**死亡率不变** | **严格限定于附件5 高危人群，禁止普筛** |

## 八、国际老年筛查框架对照

### 8.1 WHO ICOPE「内在能力」五维度（现行 2025-09 第2版手册）

| 维度 | Step 1 初筛 | Step 2 深入评估工具 |
|---|---|---|
| 运动/移动 | 起立—坐下计时、步态询问 | **SPPB**、步速、5 次起坐 |
| 认知 | 记忆下降、3 词回忆 | **MoCA / MMSE** |
| 心理 | 近两周情绪低落/兴趣减退 | **GDS-15 / GDS-5** |
| 感官（视+听） | 视物、听声是否困难 | **Snellen 视力表 / HHIE-S、耳语试验** |
| 活力（营养） | 食欲下降、非意愿体重下降 | **MNA / MNA-SF** |

来源：[WHO ICOPE 指南 2017](https://www.who.int/publications/i/item/9789241550109)、[ICOPE 手册第2版 2025](https://www.who.int/publications/i/item/9789240103726)

### 8.2 USPSTF 对 65+ 的 A/B 级推荐（要点）

腹主动脉瘤（65–75 岁曾吸烟男性，B）、骨质疏松（女性 ≥65 岁，B）、结直肠癌（50–75 岁 A；**76–85 岁选择性**；>85 岁不建议）、乳腺癌（40–74 岁每 2 年，B；**≥75 岁 I**）、宫颈癌（21–65 岁 A；**>65 岁 D**）、肺癌（50–80 岁、≥20 包年、戒烟<15 年，每年 LDCT，B）、抑郁（含 65+，B）、跌倒预防（社区 ≥65 岁风险升高者运动干预，B）、高血压（A）、丙肝（18–79 岁，B）、HIV（15–65 岁，A）等。

> ⚠️ **重要更正**（本报告据此修正）：USPSTF 对老年人**认知障碍筛查（2020）、听力损失筛查（2021）、视力筛查（2022）均为 I 级"证据不足"**，**不是 A/B 级**；前列腺癌 **≥70 岁为 D 级**。因此这三项在工具中**应作"功能评估与健康指导"呈现，不宣称是循证筛查**——这与我方引用的协和老年医学科观点（听力/口腔负担重、被低估）并不矛盾：**问题是负担巨大但缺乏筛查试验证据**，两者需分别表述。

### 8.3 老年筛查的"停止规则"（指引完全缺失）

国际共识**不是按年龄一刀切**，而是以**预期寿命、衰弱/功能状态、合并症与患者意愿**决定启动与停止：

- **AGS Choosing Wisely**：**不要对预期寿命 < 10 年者推荐癌症筛查**。
- **ACS 结直肠癌 2026**：筛查至 75 岁，条件是**预期寿命 > 10 年**。
- **ACP 乳腺癌 2026**：50–74 岁每 2 年；**≥75 岁或预期寿命有限者应讨论停止**。
- **USPSTF**：结直肠癌 76–85 岁"选择性提供"；肺癌戒烟满 15 年即停。
- 量化工具：**ePrognosis（Lee 指数、Schonberg 指数）**。

### 8.4 老年综合评估（CGA）与用药核查

- **CGA 循证**：Stuck 1993（Lancet，28 项试验）显示改善生存与功能；Cochrane 2017（住院老年）降低死亡与失能；Cochrane 2022（社区衰弱）非计划住院可能下降（RR 0.83）。
- **多重用药**：**AGS Beers Criteria 2023**、**STOPP/START v3（2023，共 190 条）**；多重用药定义为 ≥5 种药，危害含跌倒、住院、认知损害、死亡。
- **肌少症 AWGS 2019**：握力 男<28kg / 女<18kg；6m 步速 <1.0 m/s 或 SPPB≤9 或 5 次起坐≥12s；初筛小腿围（男<34cm/女<33cm）、SARC-F≥4。
- **衰弱**：Fried 表型（≥3 项）、**FRAIL 量表**（5 问）、Clinical Frailty Scale。

### 8.5 缺口总表（22 项，摘要）

| 类别 | 缺口 |
|---|---|
| **维度缺失** | 衰弱、肌少症、跌倒、内在能力、ADL/IADL、营养(MNA)、社会支持/孤独、尿失禁、老年虐待、ACP 预立照护计划 |
| **项目缺失** | 腹主动脉瘤超声、HBsAg/抗-HCV/HIV 血清学 |
| **工具缺失** | 结构化用药核查（Beers/STOPP）、听力筛查量表、GDS、SARC-F、ePrognosis |
| **规则缺失** | 癌症筛查年龄上限/停止规则、预期寿命阈值 |
| **等级不足** | 抑郁/焦虑仅为"选做"；认知/听力/视力无证据分级说明 |

（22 项逐条对照见 [国际老年预防筛查框架对照报告.md](<国际老年预防筛查框架对照报告.md>)）

## 九、中国老年人专属标准体系（工具的权威依据）★重要更正

**此前我在第六节建议"自行设计老年人模块"——这一点需要更正。** 中国已发布成套的老年医学国家卫生行业标准，**我们应当直接采用，而不是自己发明。**

### 9.1 现行标准清单（均已核实）

| 标准号 | 名称 | 状态 | 对本工具的价值 |
|---|---|---|---|
| **WS/T 888-2026** | 医疗机构老年综合评估技术操作标准 | 2026-09-01 施行 | **老年人模块的直接依据**（含完整量表清单） |
| **WS/T 887-2026** | 社区老年人跌倒预防控制技术标准 | 同上 | 跌倒分级（低/中/高）与工具 |
| **WS/T 875-2026** | 老年人认知障碍预防干预技术标准 | 同上 | 认知评估**每 12 个月一次**、干预与随访（6 个月） |
| **WS/T 878-2026** | 老年人失能预防服务标准 | 同上 | 功能评估与失能预防 |
| WS/T 876/877-2026 | 医养结合健康管理 / 健康教育服务标准 | 同上 | 机构侧服务流程 |

### 9.2 WS/T 888-2026 给出的量表清单（可直接落地）

对象：**60 岁及以上**、可通过 CGA 获益者。

| 维度 | 标准指定工具 |
|---|---|
| 躯体功能 | **ADL（Barthel 10 项）、IADL（Lawton）**；运动功能筛查（步行 400m / 登 10 阶是否困难）→ **SPPB** |
| 感官 | 视力简易评估与视觉功能；听力简易评估**或耳语试验** |
| 精神心理 | 认知筛查（3 词回忆 + 画钟）→ MMSE/MoCA；抑郁 2 问 → **GDS-15**；焦虑 2 问 → **GAD-7** |
| 社会与环境 | **Lubben 社会网络量表**；居家环境 14 项 |
| 老年综合征 | 跌倒（3 问→分级）；衰弱 = **FRAIL 量表**；尿失禁 = **ICIQ-SF**；便秘；睡眠 = **阿森斯失眠量表 AIS**；疼痛 = **NRS**；压力性损伤 = **Braden**；多重用药（全部西药/中药/保健品 + 不适当用药判断）；吞咽 = **洼田饮水试验**；营养 = **NRS2002 / MNA-SF** 筛查 → **GLIM** 诊断；**肌少症** = 小腿围（男<34/女<33cm）→ 握力（男<28/女<18kg）+ 6m 步速（<1.0m/s）→ DXA/BIA 骨骼肌指数；谵妄 |

**WS/T 887-2026 跌倒分级**：问过去一年是否跌倒 / 走路是否稳 / 是否担心跌倒 + **4 米步速 + 计时起立行走（TUG）**，风险分**低、中、高三级**。

### 9.3 政策层面的最新变化（影响数据与实现）

- **《关于做好 2025 年基本公共卫生服务工作的通知》（国卫基层发〔2025〕7号）**：自 2025 年起，**65 岁以上免费体检增加胸部 DR 正位检查和糖化血红蛋白检测**，并分类分级服务。
- 第三版《健康体检表》**含"老年人认知功能""老年人情感状态"两个粗筛字段**（阳性→MMSE / GDS），但地方培训明确其"**可不做要求**"——**非强制**，导致各地落地差异大。**这正是我们做工具的价值点**：把非强制的粗筛变成人人可用的标准化流程。
- 老年人中医体质辨识（65 岁以上，每年 1 次）为独立服务规范。

### 9.4 中国官方筛查方案的年龄上限（指引缺失，但国内方案有）

| 癌种 | 官方筛查年龄段 | 频次 |
|---|---|---|
| 肺癌 | 高风险 **50–74 岁** | 每年 1 次 LDCT |
| 结直肠癌 | 散发高危 **40–74 岁** | 结肠镜每 5–10 年 |
| 食管癌 | 高危 **45–74 岁** | 每 5 年 1 次内镜（专家共识建议 **74 岁终止**） |
| 胃癌 | 高危 **45–74 岁** | 每 5 年 1 次内镜 |

**过度筛查的国内定义**（国家癌症中心陈万青团队，JNCC 2022）：**超过推荐筛查年龄上限，或预期寿命 < 10～15 年**者接受癌症筛查。中国前列腺癌学组 2017 共识则要求**预期寿命 10 年以上**男性才定期查 PSA。

> **结论修正**：老年人模块**不是"我们需要自创"**，而是"**我们需要把 WS/T 888-2026 等国家标准数字化、并把非强制的粗筛做实**"。这让工具从"重新发明"变成"权威标准的落地实现"——**定位更稳，说服力更强，也更容易被采纳。**
