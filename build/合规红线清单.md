# 体检指导工具 · 合规红线清单（中国大陆）

> 适用形态：网页 / PWA / 小程序 / 离线 HTML
> 依据：现行法律法规与部门规章
> 声明：本清单为法规框架梳理，不构成法律意见；正式对外服务前建议请专业律师审查。

---

## 一、结论速览

| 风险类别 | PWA | 微信小程序 | 单文件离线 HTML |
|---|---|---|---|
| ICP 备案 | 国内托管**需要** | **必须**（小程序备案） | **不需要** |
| 主体 / 类目资质 | 无 | **需要**（个人主体不可做健康类目） | 无 |
| 平台内容审核 | 无 | 有 | 无 |
| 被认定为"移动应用程序" | **若宣称"下载安装"则有** | 本身就是 | 无 |
| 内容定性（诊疗/器械/广告） | **存在** | 存在 | 存在（传播面小） |

**PWA 的法律风险不比普通网站高，比小程序低**；唯一独有风险是"被当成 App"。**真正的风险在内容定性，与形态无关。**

---

## 二、PWA 独有风险：别把它宣传成"App"

- 《反电信网络诈骗法》第二十三条：设立**移动互联网应用程序**应当按照国家有关规定向电信主管部门办理许可或者备案手续。
- 《移动互联网应用程序信息服务管理规定》规范的对象是"应用程序"。
- PWA 本质是**网站**，但若你**宣传"下载我们的 App""安装到手机"**、做强化安装引导，可能被认定为移动互联网应用程序，从而被要求按 App 管理（主体资质、备案等）。

**规避做法**：定位为"**网页工具 / 一个网址**"，分享链接而非"安装包"；界面上不出现"下载 App""安装"字样。

---

## 三、备案类风险（与普通网站相同）

- 《互联网信息服务管理办法》：国家对**非经营性**互联网信息服务实行**备案**制度。
- 国内服务器 / 域名 → 必须 **ICP 备案**（免费）+ **公安联网备案**（通常 30 日内）。
- 未备案：接入服务商可停止服务，并可能被处罚。
- 境外托管或本地文件 → 无国内备案义务，但存在**速度慢、可能被拦截、微信内打不开**的问题；与机构合作时对方通常会要求备案。
- **阶段 1 的单文件 HTML 若不公开托管，完全没有备案义务。**

---

## 四、内容定性风险（真正的大头）

### 4.1 医疗器械边界（最严重）

若工具被认定为"用于疾病**诊断、治疗、监护**"的医疗器械软件，需取得注册证。**健康管理 / 科普类一般不作为医疗器械管理。**

**红线**：不要出现"帮你**筛查**肺癌""**诊断**你的风险""**检测**你是否患病"。
**合规写法**："根据国家指引，您属于 ×× **高风险人群**，**建议与医生讨论**是否做 ×× 检查。"
→ 给的是「**指引依据 + 就诊建议**」，不是「诊断结论」。

### 4.2 互联网诊疗边界

《互联网诊疗监管细则（试行）》（国卫办医发〔2022〕2号）明确规定：
- "**人工智能软件等不得冒用、替代医师本人提供诊疗服务**"
- "**处方应由接诊医师本人开具，严禁使用人工智能等自动生成处方**"

**红线**：不给用药建议、不给治疗方案、不说"不用去医院"、不使用"AI 诊断"表述。

### 4.3 《互联网广告管理办法》第八条 ★对你们最关键

**原文**："禁止以介绍健康、养生知识等形式，变相发布医疗、药品、医疗器械、保健食品、特殊医学用途配方食品广告。介绍健康、养生知识的，**不得在同一页面或者同时出现相关**医疗、药品、医疗器械、保健食品、特殊医学用途配方食品的**商品经营者或者服务提供者地址、联系方式、购物链接等内容**。"

**含义**：只要页面里出现**体检机构/医院的地址、电话、二维码、预约链接、返佣**，无论是否收费，都可能直接违法。

> 这条把"**非营利、零商业导流**"从道德选择变成了**法律必需**。坚持非营利 + 不挂任何机构链接，即基本规避本项风险。

来源：[《互联网广告管理办法》（国务院公报）](https://www.gov.cn/gongbao/2023/issue%5f10506/202306/content_6885261.html)

### 4.4 虚假健康信息

《网络信息内容生态治理规定》禁止散布虚假健康养生信息。
本工具内容**逐条引自国家卫健委指引与 WS/T 国家标准**，这是最强的合规护城河——因此**必须标注依据与版本号**。

## 五、个人信息保护

- 《个人信息保护法》：**健康信息属于敏感个人信息，处理需取得单独同意**。
- 本项目**零采集**，基本完全规避。
- 需堵住两个漏洞：
  1. **不要埋第三方统计 SDK**（百度统计、友盟等会采集 IP / 设备标识）
  2. 谨慎使用境外 CDN 加载字体 / 脚本
- PWA 的 Service Worker 仅缓存静态文件，不涉及个人信息，安全。

---

## 六、民事与声誉风险

- 若有人按清单漏查导致延误诊断，可能产生纠纷。
- **免责声明不能免除法定责任**，但能显著降低风险与责任认定概率。
- 建议：显著免责声明 + "请持此清单咨询医生" + 标注依据版本与更新日期 + **医学专业人士署名审校**。

---

## 七、执行清单

### ✅ 必须做

1. **显著免责声明**：不构成医疗建议或诊断，不能替代医师面诊，请遵医嘱。
2. **标注依据与版本**：国家卫健委《成人健康体检项目推荐指引（2025年版）》＋ WS/T 888-2026 等标准，并写明更新日期。
3. **结果表述**统一用"高风险人群 / 建议与医生讨论"，**禁用"诊断 / 确诊 / 筛查出"**。
4. 高风险结果给"**建议尽快就医**"，不给病名结论。
5. **全站零个人信息采集**，不埋第三方统计 SDK。
6. **医学专业人士审校并署名**。
7. 国内托管 → 老实办理 ICP 备案 + 公安联网备案。

### ❌ 绝对不能做

1. **页面出现任何体检机构 / 医院的地址、电话、二维码、预约链接、返佣**（广告法第八条）。
2. 使用**国家卫健委 / 疾控中心的名义或 logo**，暗示官方背书。
3. 给出**用药或治疗方案**建议。
4. 宣称"**AI 诊断**""智能诊断"。
5. 把工具宣传为"**App 下载**"（触发移动应用程序监管）。

---

## 八、对项目形态的结论

- **阶段 1 用单文件离线 HTML 起步，法律暴露面最小**：不开公网、无备案义务、无平台审核、不涉及 App 认定。
- 阶段 2 上 PWA 时，只增加"国内托管需备案"一项，并注意不要宣传成 App。
- 阶段 3 上小程序时，**主体资质与类目**才是最大障碍（须提前解决）。

**你们"非营利 + 零采集 + 严格引用国家指引 + 不挂商业链接"这四条，恰好把四类主要风险全部对冲。**
